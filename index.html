About context

The About section exists to describe what this test repository is actually for. In short: it's a scratchpad where Omarchy and Hermes can both inspect and modify a single artifact — this very file — and observe each other's changes in real time.

Omarchy is the workspace/orchestration side of the experiment; Hermes is the agent that reads, writes, and reasons over the same files. By keeping everything in one repository, we get a clean integration point with no external dependencies.
